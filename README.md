# Algorithm Challenge #5 – Sum Each Column in a Separate Array (Level 3)

🧮 Problem Description  
-
This program generates a 3x3 matrix of random numbers, calculates the sum of each column, stores the results in a separate 1D array, and prints them.

Unlike Challenge #4, which printed column sums immediately, this challenge emphasizes **storing intermediate results** for better flexibility.

---

💡 What You’ll Learn
-
- Column-wise traversal of 2D arrays
- Storing computation results in 1D arrays
- Separation of computation and presentation
- Structured, modular, and maintainable code
- Algorithmic thinking at Level 3

---

🧩 Example Output
-
The following is a 3x3 Random Matrix:

 12   45   30  
  8   19   67  
 22   14   10  

The following are the sum of each column:

Column 1 Sum = 42  
Column 2 Sum = 78  
Column 3 Sum = 107
